# Editorial image slots

Bunny Quiz does not download or hotlink photography. Add only images supplied by
the project owner or already licensed for this repository.

Suggested organization:

- `editorial/`: hero and result imagery;
- `eras/`: album-era photography;
- `archive/`: historical MusicQuiz material.

Set the local paths in `CONFIG.assets.photos` inside `js/config.js`. If a file is
missing or fails to load, the interface keeps its designed typographic fallback.
